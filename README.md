# 55user3125 Reference Reader

A personal, local, read-only MCP connector planned by 55user3125 for working with the owner's own Pinterest boards and Pins as creative references in Codex.

The connector is intended to use the official Pinterest API and OAuth authorization. Its intended functions are to list the account owner's boards, retrieve their saved Pins and associated metadata, and provide selected results to Codex at the owner's request. It is not intended to create, edit, or delete Pinterest content, serve other users, or run advertising.

Status: under development; Pinterest API access and the working connector are not yet approved or verified. Capabilities depend on Pinterest approval, permissions, and implementation.
